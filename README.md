# Xiakra Brand and Social Guidelines

Public web version of the Xiakra brand and social guidelines deck, served with GitHub Pages.

**Live:** https://franzhiro.github.io/xiakra-guidelines/

The page is static: `index.html` plus `img/`, `vid/` and `fonts/`. The fonts are Instrument Sans and JetBrains Mono under the SIL OFL 1.1; their licences are in `fonts/`.

To update the site, edit `index.html` or replace the assets, then commit and push to `main`. GitHub Pages republishes within about a minute.

The page asks search engines not to index it (`noindex`). Anyone with the link can still open it.
